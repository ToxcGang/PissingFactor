# Credits and asset provenance

- **ToxcGang** — project owner, concept, and original PissingFactor work.
- **Deep Field Games / Playstack** — Abiotic Factor.
- **Running With Scissors** — Postal 2, the gameplay inspiration. No Postal
  assets or sounds are included.
- **Epic Games** — Unreal Engine and editor tools.
- **UE4SS contributors** — runtime modding framework.
- **igromanru** — [Abiotic Factor UE4SS configurations](https://github.com/igromanru/AF-UE4SS)
  and publicly documented continence integration references.
- **Abiotic Factor modding community** — compatibility research and guides.

PissingFactor's gameplay logic is original. Referenced third-party projects are
not vendored into the mod. The UE4SS prerequisite is downloaded separately and
retains its own license. Unreal's editor is a developer prerequisite, not part
of the player download.

Original generated assets are described in `assets/manifest.json`. Game skeleton
metadata used locally to build compatible animations stays outside source control.
